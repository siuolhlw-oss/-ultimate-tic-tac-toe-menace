# 超級井字棋科展研究

目標：研究 MENACE 延伸版在超級井字棋中的學習效果，並探討將全盤旋轉、鏡射視為同構後的合法局面數及完整棋譜數。

參展目標為雲林縣 115 學年度國中科展。文件建立日期：2026-10-06（Asia/Taipei）。已完成 Python＋Streamlit＋SQLite 本機原型、研究文件與功能驗證；外部部署、正式比較實驗及完整變化數枚舉尚未完成。

- [本機操作指南](本機操作指南.md)：首次安裝、啟動、模型種子、命令列、備份及匯出。
- [驗證紀錄](驗證紀錄.md)：52 項測試、40 局隔離試跑及已知限制。
- [研究日誌](研究日誌.md)：工具協助事實與學生後續研究紀錄入口。

## 最重要的研究約定

1. 大格先三連線者獲勝；已贏或填滿的小盤封閉。落子的小格編號指定對手下一個大格；若指定盤封閉，改為自由選擇未結束小盤。
2. 位置用兩位數表示，例如 `35` 為大格 3 的小格 5。大小格皆採由左至右、由上至下的 1–9 編號。
3. **MENACE 每個盒子代表完整局面，包含行動方及下一手限制；盒內只能包含當下合法下法。10% 隨機探索也不得越過合法位置限制。**
4. 旋轉／鏡射必須同時作用於整盤、大小格編號及指定下一個大格。同構合併學習經驗，不刪除原始棋譜。
5. 初始每合法動作權重 3；整場勝／和／負分別 +3／+1／−1，最低 0。小盤勝利不提前獎勵；整場結束才更新自己選過的下法。
6. 訓練中遇過的局面數只是已探索數量，不得冒充完整枚舉結果；示範棋譜不得冒充實測資料。

追加訓練：`continue_5000.cmd` 在獨立副本中接續原模型，追加 5,000 局至累計 6,000 局；同一命令可中斷續跑且完成後不重複加局。本次狀態、容量預算與完整匯出方式見 [續訓紀錄](續訓紀錄_6000局.md)。

儲存優化：完整千局副本從 1.80 GB 縮至約 171 MB，原值逐表核對及重播通過。雙擊 `play_compact.cmd` 可開優化副本的凍結 PK 入口（8504）。原追加訓練保持 v2；單次銜接作業等待其完整交付後，再建立並驗證 6,000 局的 v3 副本。詳見 [資料庫優化紀錄](資料庫優化紀錄.md)；原檔保留，尚未宣稱 6,000 局或其完整遷移已完成。
