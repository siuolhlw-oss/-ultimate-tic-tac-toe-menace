# 6,000局學生觀察網站

這是科展專案的獨立展示網站，Sites專案身分保存在 `.openai/hosting.json`。部署經使用者於2026-10-19確認，採持有連結即可瀏覽、匿名提交建議。

## 資料範圍

- `public/explore/data.json`：已完成的6,000局、353,495手原始棋譜；不含測試、人類PK或學生探索。
- 匯出器 `tools/export_student_atlas.py` 位於上一層研究專案，使用唯讀v3連線，逐手核對合法性、狀態鍵、指定盤、版本及終局。
- 原始方向、X/O身分及順序保留；圖上以奇數○對應原始X、偶數×對應原始O。SVG由瀏覽器按需產生，沒有改寫研究紀錄。
- 計數是這6,000局的觀察值，不是全部合法變化，也不是策略收斂證明。兩張指定盤圖片另標為規則示例。

## 學生與教師

學生可逐步回放、切換全盤同構下法、試走合法分支、查看樣本與界限，並附上目前局號、手數與探索路徑提交建議。表單不要求登入、姓名、學號、聯絡方式；文字內容僅供教師查看。只有看到「已保存」與收件編號才算提交成功，失敗保留表單並可用同一收件ID重試。

建議透過獨立D1資料庫保存，與訓練模型分開。教師入口為 `/teacher`，經平台ChatGPT登入後，伺服器比對保密設定 `TEACHER_EMAIL`。一般訪客與其他登入帳號都不能讀取回饋或下載CSV。回饋按50則分頁；單次CSV匯出最多10,000則，對可能的試算表公式加保護。

## 開發及部署

使用Sites提供的Vinext starter及官方安裝、建置、來源同步和發布工具；保留 `sites()` 整合。新增的D1資料表由Drizzle產生SQL遷移，發布時由Sites套用。不得在請求中建表。

本機需Node.js及npm，從本站目錄執行 `npm ci`、`npm run build`。本機D1依starter README套用SQL；預覽資料庫與正式D1分開。`.sites-runtime`、`.wrangler`、`.env*`及`.dev.vars*`都不得上傳。平台憑證只透過官方來源helper的隱藏stdin傳遞。

研究專案的 `tests/student_site_ui.cjs` 核對全部棋譜、DOM互動與失敗重試；本站 `tests/feedback.test.mjs` 核對欄位、教師判斷及CSV。`tools/verify_student_api.py` 限制在loopback隔離D1驗證實際保存，不對正式站點寫入測試回饋。
